# Contributions and provenance

The original collaborative STAT 486 course project (Fall 2025) lists Yuexi Dai, Xinrui Yu and Mengting Qiu as authors. Yuexi Dai confirmed participation. The supplied material does not establish a precise task-by-task allocation or sole authorship.

The November 2026 methodological audit, maintained pipeline, new analyses, diagnostics, visualizations and documentation were prepared at Yuexi Dai's request with OpenAI Codex coding and analytical assistance. The models were executed and checked locally. This does not establish independent design or implementation by any individual. The extension is distinct from the original course work and uses the documented public data version in DATA_SOURCES.md. Missing course CSVs were not reconstructed from fitted results.

The recovered course source is archival, retains known limitations and uses portable data-path placeholders. Hashes of the supplied local source files are recorded in docs/source_manifest.json.
